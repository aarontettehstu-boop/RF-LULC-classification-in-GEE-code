# RF-LULC-classification-in-GEE-code
This code was used to perform RF LULC classification for the years 2015, 2020, 2025 in GEE. The study area was Kwaebibirem district in Ghana.
The script was executed with signature training data for each classification year.
#########################################################
How to Run the Google Earth Engine (GEE) Scripts:
Follow these steps to run the Land Use and Land Cover (LULC) classification scripts for 2015, 2020, and 2025.
1.	Download the Word document containing the links to the GEE scripts.
2.	Open the Word document and locate the link for the year you want to process: 2015, 2020, or 2025.
3.	Click the relevant link. It will open the corresponding script directly in the Google Earth Engine Code Editor.
4.	Run the script. In the GEE Code Editor, click the Run button to execute the classification.
5.	View the results. Once processing is complete, inspect the generated LULC classification outputs in the map display and other output panels, as applicable.
